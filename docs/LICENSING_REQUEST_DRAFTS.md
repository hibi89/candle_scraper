## 업비트 문의 초안

**제목:** Open API 연동 Windows 소프트웨어 유상 배포에 대한 서면 허가 가능 여부 문의

안녕하세요. 업비트 공개 시세 API를 사용하는 개인 개발형 Windows 소프트웨어의 판매 가능 범위를 사전 확인하고자 문의드립니다.

개발 제품은 고객의 PC에서 실행되며, 고객이 선택한 원화 마켓의 분·일·주·월별 캔들을 조회해 로컬 SQLite 및 CSV로 저장하는 프로그램입니다. 주문·출금·계정 조회, API Key 저장이나 사용자 데이터의 개발자 서버 전송은 수행하지 않습니다. 소프트웨어 판매 시 거래소의 실제 과거 시세 데이터를 ZIP 안에 포함하지 않으며, 구매자 PC가 공식 공개 API에 직접 접근합니다.

현재 Open API 이용약관 제6조 제3항의 유상 배포·이용 허락 금지 규정을 인지하고 있으므로, **서면 허가 없이 유통하지 않고 있습니다.**

다음 사항의 허가 가능성과 별도 라이선스 계약 절차를 확인 부탁드립니다.

1. 시세 공개 API 연결 기능을 포함한 상용 Windows EXE의 유상 양도·배포·사용권 판매를 예외적으로 승인받을 수 있는지
2. 고객이 자신의 PC에서 공개 API를 호출해 수집·보관한 데이터를 개인 용도로 사용하는 범위와 제한 사항
3. 판매자의 시세 데이터 재배포 없이 프로그램만 유통할 경우에도 적용되는 제한·저작권 고지·출처 표시 요건
4. API 호출량 제한, 여러 고객이 사용하는 경우의 상업적 이용 계약·수수료·기술 요건
5. 공식 상표·로고를 포함하지 않고 거래소 이름을 지원 목록으로 명시해도 되는지

필요한 제품 기능 명세 및 API 호출량 근거를 요청하시면 제공하겠습니다. 승인 가능 여부 및 조건을 **서면 답변**으로 부탁드립니다.

감사합니다.

## 빗썸 문의 초안

**제목:** 빗썸 Public API 연동 캔들 수집기 유상 판매 및 데이터 사용 범위 서면 확인 요청

안녕하세요. 빗썸 Public API를 이용하는 Windows용 로컬 캔들 수집 프로그램의 유상 배포 가능 여부를 확인하려 합니다.

제품은 고객 PC에서 거래 대상 원화 마켓 시세를 공개 REST API로 조회하여 고객 PC의 SQLite/CSV에 저장합니다. API Key와 거래 기능을 사용하지 않으며, 판매용 ZIP에는 수집된 시장 데이터나 고객별 파일을 포함하지 않습니다. 서버에서 시장 데이터를 중계·판매하지 않습니다.

귀사의 과거 공식 API 이용약관에는 API를 통해 획득한 시세 등 데이터의 제3자 양도 제한이 포함되어 있음을 확인했습니다. 현재 적용되는 약관이 바뀌었을 가능성도 있으므로 다음 사항에 대해 안내 부탁드립니다.

1. 데이터 미포함 형태의 EXE **소프트웨어 자체**를 유상 판매하거나 라이선스 제공하는 것이 허용되는지
2. 고객이 본인 PC에서 조회한 시세 데이터를 로컬에 저장하고 CSV로 내보내는 행위의 허용 범위
3. 시세 데이터의 고객 간 공유·재판매·재배포 제한, 필수 고지 문구와 출처표기 방법
4. 사업자·상업용 사용자의 API 호출 한도와 서면 허가·별도 계약이 필요한 조건
5. 판매용 제품 설명에 '빗썸 데이터 조회 지원'을 기재하는 경우 상표 사용 조건

**서면 허가가 확인되기 전에는 판매·배포하지 않겠습니다.** 정확한 최신 약관과 공식 담당 문의 경로를 알려주시면 감사하겠습니다.

## 결정 절차

- **허가 확인:** 업비트/빗썸의 제품 재판매·최종 고객 데이터 보관·재배포 제한을 각각 독립적으로 명확히 적은 공식 서면 회신을 보존. 구두 안내나 단순 API 공개 사실로 대체하지 않음.
- **허가 거부 또는 무응답:** 현행 업비트·빗썸 연동형을 크몽에 출시하지 않음. 사용자의 별도 승인 후에만 정식 허가를 받은 다른 데이터 공급자 모델이나 오프라인 CSV/SQLite 제품 모델로 범위 전환.
- **개발/판매 분리:** Windows 빌드·단위 테스트 PASS는 법률적 허가를 의미하지 않음. 허가 확보 후에도 소비자 Windows 10/11, 백신, 사용자 설명, 복구, 지원 범위와 동일 SHA의 최종 테스트를 완료해야 출시 가능.

참고: `docs/COMMERCIAL_API_POLICY.md`, `docs/RELEASE_CHECKLIST.md`, `STATUS.md`. 모든 대외 발신은 사용자 승인 전 진행하지 않음.
